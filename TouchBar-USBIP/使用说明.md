# Touch Bar 可用版本

本机已实测屏幕显示和触摸音量调节成功。适用这台 MacBookPro16,1 / Windows 10，使用官方 usbipd-win 5.3.0 的已签名 VBoxUSB 驱动和本机界面程序。保持安全启动，不需要 WSL、测试模式或重启。

## 日常使用

直接双击本目录文件：

| 文件 | 用途 |
| --- | --- |
| Start-Media.cmd | 启动媒体栏，提供播放、音量、屏幕亮度及键盘背光增减按钮 |
| Start-Functions.cmd | 将默认栏切换为 F1–F12 |
| Stop.cmd | 退出程序；退出后屏幕会黑，这是连接释放后的表现 |
| Restore-Apple.cmd | 停止程序、取消 USBIP 绑定并恢复 Apple 原版按键；会出现系统管理员确认 |
| Check.cmd | 程序退出后运行；检查显示握手、触摸端点和首帧确认，完成后退出 |
| Enable-Autostart.cmd | 启用当前用户登录后自动显示 Touch Bar（已启用） |
| Disable-Autostart.cmd | 禁用登录自启动，不停止当前正在运行的界面 |

两个启动入口也可以在程序运行中切换默认栏。媒体栏不再显示额外的 `F1–F12` 切换按钮，功能栏只显示 F1–F12。

物理 Fn 按放已经用户实测通过：单独按住 Fn 时临时显示 F1–F12，松开后恢复之前的栏。当前根据 Apple 驱动的事件推断按下和松开；Fn 与普通键同时操作时可能漏判或不同步。出现这种情况可松开 Fn 后双击 `Start-Media.cmd`，恢复媒体栏并重置 Fn 状态。

Chrome / Edge 的专用配置优先，切回其他应用恢复默认栏。按住 Fn 时功能键栏优先。

打开文件属性等 Explorer 对话框时，会保留“确定／取消／应用”等触摸按钮。普通文字已改用微软雅黑 UI，修复中文显示为方框的问题。

键盘背光增减已由用户实测确认实体灯光变化，调节时不显示任何桌面提示。屏幕亮度按钮调用 Windows 10 自己的左上角竖向亮度条，数值、动画和自动隐藏由系统负责；已移除本程序的自绘提示。本机 WMI 支持的亮度档位为 0–90，90 是该接口报告的最高档。

若之前已恢复 Apple 原版，启动入口会先请求系统管理员权限完成精确设备绑定，再以启动它的普通用户权限运行界面。日常从文件资源管理器双击即可，不需要以管理员身份运行界面程序。

恢复原版时保留已安装的 USBIP 软件，并暂停界面自启动，方便下次选择。再次手动启动媒体栏或功能栏会取消暂停；若使用了 Disable-Autostart.cmd，则需通过 Enable-Autostart.cmd 重新启用登录启动项。

## 开机自动显示（已配置）

当前用户 MAC 登录 Windows 桌面后，系统 PowerShell 会隐藏运行 AutoStart.ps1，等待 USBIP 服务和 Touch Bar 设备就绪，再以普通桌面用户运行界面。保留上次选择的默认栏，不弹管理员提示；设备未就绪时最多等待约 150 秒，启动失败最多重试 3 次。界面成功运行后启动助手退出，Stop.cmd 仍可正常停止界面。

另有系统开机任务 `TouchBar USBIP Boot Recovery`，开机约 10 秒后检查精确的 Apple 8302 设备。仅在出现已确认的 VBoxUSB 代码 37 / 0xC0000034 故障时，先启动其监控服务，再重启这一设备一次；设备健康或已恢复 Apple 原版时不修改设备。任务执行受管理员保护的 `C:\Program Files\TouchBar-Startup\TouchBarBootRecovery.ps1`，不运行桌面界面、不重新绑定驱动。

登录启动项与系统任务均已安装验证：用注册的同一条启动命令实测启动成功，用户确认显示和音量按钮正常；系统任务最近执行返回 0。最终配置完成后的再次整机重启、登录前画面及睡眠唤醒尚未验收。该方案在登录桌面后显示自定义栏，不承诺登录界面显示。

请保留本目录路径。登录启动日志为 `autostart.log`；开机设备恢复日志为 `C:\Program Files\TouchBar-Startup\boot-recovery.log`。

## foobar2000 同步歌词

播放 foobar2000 中的歌曲时，Touch Bar 自动显示单行居中的当前歌词。未唱部分为白色，已唱部分随进度染为紫蓝渐变色；字体通常为 34 像素，长句缩小到 28 像素，再长则平滑滚动。歌词页左侧为上一首、播放/暂停、下一首及 foobar2000 图标，右侧为静音和音量加减。歌词页不显示屏幕亮度、键盘背光按钮，也不显示下一句或底部进度线。

播放按钮宽 144 像素，音量加减宽 128 像素，间隔 20 像素。点按有高亮反馈，滑动到相邻按钮不触发新操作。播放按钮直接控制 foobar2000，支持连续点按。

主栏和歌词页的全部图标统一相对调整前放大 20%，按钮布局与触摸区域不变。上一首、播放／暂停、下一首保留原来的图标样式，字号从 30 增至 36；音量、屏幕亮度、键盘背光继续使用加粗轮廓，播放器图标同步放大。本次图标调整的实际观感待用户确认。

逐字着色每帧直接查询完整时间表，跨字不再等待 250 毫秒的播放器数据更新；细小时间误差平滑校正，拖动进度和切歌立即重新定位。文字采用较清晰的字重、完整白色和更亮的紫蓝色，按面板原生像素绘制。

中文使用微软雅黑，韩语使用 Malgun Gothic，日语使用 Yu Gothic UI；同一句混合中／英／日／韩时逐段回退到具有对应字形的字体，居中和着色使用相同的字宽。使用本机现有字体，无需额外安装。

歌词页可见时，程序保持独立的 Touch Bar 背光接口打开，每秒确认全亮状态，避免空闲自动调暗／息屏。回主栏、暂停或退出歌词页后释放保持。该硬件接口提供关／暗／全亮三档；已确认使用全亮档，不提供虚构的亮度百分比。电脑自身睡眠和锁屏策略保持原样。

2026-11-09 实机验收：用户确认着色平滑、韩语／日语显示正常、连续约 60 秒无操作仍保持亮屏，文字清晰度正常。此前单行居中、播放器图标返回主栏、4 秒自动返回及暂停停留主栏也已确认正常。

- 按住 Fn 显示 F1–F12，松开恢复歌词。资源管理器属性对话框仍优先显示“确定／取消／应用”。
- 暂停时回到完整主栏：屏幕亮度、键盘背光、上一首／播放／下一首、音量；主栏按钮均宽 150 像素，没有歌词或歌名。暂停期间一直停留主栏，点主栏播放按钮恢复歌词。
- 播放期间点下一首右侧的 foobar2000 图标可临时返回完整主栏。从最后一次触摸松开后计时，4 秒没有继续触摸会自动返回歌词页；按住主栏按钮时不会跳页。停止播放或退出 foobar2000 后恢复默认界面，播放器异常退出时最多约 3 秒恢复。
- 带逐字时间戳的歌词按原始时间着色；普通 LRC 只有每句时间，句内着色按时间估算，并非音频识别出的精确逐字时间。已核对《再见只是陌生人》的现有 LRC 含逐字时间，新版按这些原始时间推进颜色。
- 自动读取音频旁的同名 `.lrc`、音频内嵌的带时间戳歌词，以及当前 foobar2000 的 `profile\lyrics` 目录。支持未填写标签、以“歌手-歌名”命名的 WAV，包括《再见只是陌生人》。现有 ESLyric 下载到该目录的歌词会在约 5 秒内被重新检测。
- 歌曲没有同步歌词时显示歌名。当前版本复用已有歌词，不额外联网搜索下载；匹配不明确的歌词不会强行显示。拖动播放器进度时按新的播放位置同步。
- 登录后原自启动项会加载新版 Touch Bar；foobar2000 打开后联动脚本自动加载，无需另开歌词程序。请保留本目录位置和现有 foobox 底部播放面板。
- 如需关闭歌词模式，在 `app\settings.json` 的最外层添加 `"lyricsEnabled": false`；保存后自动生效。

布局参考 [Apple 的 Touch Bar 使用说明](https://support.apple.com/guide/mac-help/use-the-touch-bar-mchlbfd5b039/mac) 中“应用操作区＋右侧 Control Strip”的组织方式。歌词与暂停返回主栏属于按本机使用需求实现的交互规则。

## 自定义

编辑 `app/settings.json` 设置应用、按钮、快捷键、文字、颜色和图标。程序会自动重载。诊断状态在 `app/WindowsTouchBar.status.log`，异常在 `app/WindowsTouchBar.error.log`，亮度、背光及 Fn 诊断在 `app/WindowsTouchBar.controls.log`。请按时间判断，旧错误日志不表示当前仍有故障。

本版本仅连接 `127.0.0.1:3240`，且只导入唯一的 Apple `05ac:8302`。安装器创建的 USBIP 局域网防火墙放行规则已禁用；没有共享键盘、触摸板或其他设备。USBIP 服务是自动启动服务，Touch Bar 驱动绑定会保留。

驱动和源码验证证据在 `../verification-usbip-20261108/`，显示协议来源及许可证见 `app/TRANSPORT-NOTICES.md` 和保留的源码。请保留整个 touchbar 工作目录，不要单独移动这些启动脚本。
