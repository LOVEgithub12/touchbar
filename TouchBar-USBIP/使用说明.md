## 日常入口 / Daily entry points

| 脚本 / Script | 用途 / Purpose |
|---|---|
| 根目录 / root `Start-Media.cmd` | 媒体栏 / Media bar |
| 根目录 / root `Start-Functions.cmd` | 显式 F1–F12 页 / Explicit function page |
| 根目录 / root `Stop.cmd` | 停止并取消等待中的启动 / Stop and cancel pending startup |
| 根目录 / root `Enable-Autostart.cmd` | 启用当前用户登录启动 / Enable current-user login startup |
| 根目录 / root `Disable-Autostart.cmd` | 关闭登录启动 / Disable login startup |
| 本目录 / this directory `Check.cmd` | 停止应用后检查设备 / Check hardware after stopping the app |
| 本目录 / this directory `Restore-Apple.cmd` | 恢复 Apple 显示驱动，需要单独管理员步骤 / Restore Apple's display driver, with a separate administrative step |

需要 PowerShell 7 (`pwsh.exe`)。首次克隆先在仓库根目录运行 `tools\Build.ps1 -PrepareRuntime` 并完成 USB/IP 配置。`app/` 不提交到 Git。日常主应用以普通桌面用户启动；不要把管理员启动当作快捷键权限修复方式。

PowerShell 7 (`pwsh.exe`) is required. On a fresh clone, run `tools\Build.ps1 -PrepareRuntime` from the root and complete USB/IP setup first. `app/` is not checked into Git. Run the app as a normal desktop user; elevating the whole app is not a general shortcut-permission fix.
