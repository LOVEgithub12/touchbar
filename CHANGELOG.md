## 2026-11-11 — 媒体、歌词与频谱更新 / Media, lyrics and spectrum update

相对最初源码提交 `5545f6c` 的累计更新。 / Cumulative changes since initial source commit `5545f6c`.

### 新增 / Added

- **显式 F 页**：左侧固定 F / 1–12 图标切换，独立返回按钮，避免物理 Fn 推断状态残留。 / Fixed left F / 1–12 page selector and return button, avoiding stale inferred physical Fn state.
- **第二种歌词背景**：实时频谱；点击歌词循环极光、频谱、关闭，选择持久化。 / Live spectrum as a second lyric background; tap to cycle Aurora, Spectrum and Off, with persistent preference.
- **频谱分析**：512 个对数频带、4096/2048 双窗、立体声功率合并；区分低音和中高音，输入静音后衰减。 / 512 logarithmic bands, dual 4096/2048 windows and stereo power combination; distinct bass/mid/treble response with silence decay.
- **多层粒子**：独立发射、短时悬停、下落与淡出；右半区提升纵向分布、点芯亮度与可见尺寸，适应 60 px 高的实物。 / Independent particle emission, brief dwell, fall and fade; greater right-half vertical spread and brighter, more visible cores for the 60 px panel.
- **规范文档**：完整中英文首页、安装与操作指南，双语开发/贡献/更新/授权说明，生产代码生成的原比例图片与动态 GIF。 / Chinese/English homepages and installation/usage guides, bilingual development/contribution/changelog/notices, native-ratio images and animated GIFs generated by production code.
- **开发入口**：构建和离线检查脚本、文档渲染模式、Windows GitHub Actions 工作流。 / Build/check helpers, documentation rendering mode and Windows GitHub Actions workflow.

### 改进 / Changed

- 绸带中区加宽，细淡上下波、星点与边缘渐隐；保留两侧较明显的星尘脉动与空白区过渡。 / Wider center ribbons, faint upper/lower waves, stars and blended edges; retained visible side dust and transitions.
- 绸带平滑包络与弱音支撑，避免短时间大幅上下跳动和持续声音时突然消失。 / Smoother ribbon envelopes and quiet-signal support reduce abrupt vertical jumps and disappearance during sustained audio.
- 歌词页媒体按钮只收短底部背景，增加下方星尘可见空间；主栏轻微右移，F 图标与其他控件风格一致。 / Shortened only lyric-page button-fill bottoms to expose dust; slightly shifted main bar and consistent F-switch styling.
- 前台规则明确为播放优先，暂停后恢复浏览器等配置栏；播放器入口回主栏后从最后一次释放计时。 / Playback retains priority, while configured app bars return after pause; idle return is timed from the last release.
- 构建助手从干净源码恢复依赖，并可准备运行目录，保留已有设置。 / Build helper restores dependencies from a clean source tree and optionally prepares runtime files while preserving existing settings.

### 修复 / Fixed

- 任务管理器等提权前台窗口中，普通音量注入被 UIPI 阻挡：单独音量/静音改走 Shell 系统命令，保留原生 OSD 与连发。 / UIPI blocked injected volume keys over elevated windows such as Task Manager; standalone volume/mute now use Shell commands, preserving native OSD and repeat.
- usbipd UTF-8 JSON 在 Windows PowerShell 5.1 被默认代码页误解码：统一显式 UTF-8，检查超时、stderr 与退出码。 / Explicit UTF-8 decoding prevents usbipd JSON corruption under Windows PowerShell 5.1; timeout, stderr and exit codes are checked.
- 停止命令可取消等待/初始化中的启动 helper；手动启动等待 RUNNING，不再把初始化失败报为成功。 / Stop cancels waiting/initializing helpers; manual launch waits for RUNNING instead of reporting failed initialization as success.
- 按钮销毁/换目标时释放旧命令、取消连发，避免迟到的按键及误导航。 / Disposing buttons or changing targets releases old commands and cancels repeats to avoid late key presses and stray navigation.
- 歌词页反复变暗：硬件过渡状态下重试全亮/常亮请求。 / Retry full/on backlight requests during hardware transitions to prevent periodic lyric-page dimming.
- 独立歌词检查排除图形渲染器，避免新频谱源码引入未声明的图形依赖。 / Keep graphics renderers out of standalone lyric checks to avoid undeclared graphics dependencies.
